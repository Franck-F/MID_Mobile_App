Couches transverses

Common : exception filters globaux · interceptors logging/metrics · pipes validation (class-validator + Zod) · response transformer
Jobs : BullMQ sur Redis · cron sync chrono · génération PDF · envoi batch notifs · retry webhooks MoMo · cleanup inscriptions expirées
Webhooks : endpoints publics signés pour MoMo Orange, MoMo MTN, prestataire chrono (handlers idempotents)
Observability : Sentry (erreurs), Pino (logs JSON), Prometheus/Grafana (métriques), health checks /healthz /readyz

Auth flow

1. Mobile → Supabase Auth (signup/login email OTP ou téléphone +237 OTP)
2. Supabase → Mobile : JWT (accessToken + refreshToken)
3. Mobile → NestJS API : Authorization: Bearer <JWT>
4. NestJS valide le JWT via JWKS Supabase (cache 1h), récupère user_id
5. NestJS charge le profil local (table users synchronisée via webhook Supabase à l'inscription) + rôles
6. Guards (AuthGuard, RolesGuard) appliqués sur les controllers
7. Refresh : mobile gère via Supabase SDK, NestJS ne s'en occupe pas
