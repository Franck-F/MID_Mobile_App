Section 5 / 7 — Modèle de données

Postgres · ~22 tables · multi-tenancy par édition · audit trail immutable sur paiements

Entités principales et relations
👤 User
id (uuid, FK Supabase Auth)
email, phone, locale
display_name, photo_url
role (runner/spectator/staff/admin)
preferences (jsonb)
created_at
🏁 Edition
id, year, name
start_date, end_date
registration_open_at
registration_close_at
status (draft/open/active/closed)
🏃 Race
id, edition_id (FK)
category (marathon/half/10k/kids)
distance_m, price_xaf
capacity, start_time
course_id (FK)
🗺️ Course
id, name
polyline (geojson)
elevation_profile (jsonb)
start_lat/lng, finish_lat/lng
distance_certified_m
📍 Checkpoint
id, course_id (FK)
name (5K, 10K, 21K…)
distance_from_start_m
lat, lng
order
📝 Registration
id, user_id, race_id
tshirt_size, emergency_contact
medical_cert_id (FK)
bib_number (assigned post-paiement)
status (pending/paid/confirmed/cancelled)
team_id (FK nullable)
🩺 MedicalCertificate
id, user_id
file_url (S3 OVH)
uploaded_at, expires_at
validation_status
validated_by (staff_id)
💳 Payment
id, registration_id
amount_xaf, currency
provider (orange_momo/mtn_momo/card)
provider_tx_id, idempotency_key
status (initiated/pending/succeeded/failed/refunded)
initiated_at, completed_at
📒 PaymentAuditLog
id, payment_id
event_type, payload (jsonb)
created_at
append-only, jamais modifié
⏱️ TimingEvent
id, registration_id
checkpoint_id (FK)
recorded_at (timestamp précis)
chip_id, raw_payload (jsonb)
source (provider/manual)
🏆 Result
id, registration_id (unique)
finish_time_ms, gun_time_ms
net_time_ms (chip)
rank_overall, rank_category, rank_gender
status (finished/dnf/dq)
📜 Certificate
id, registration_id
pdf_url (S3 OVH signé)
generated_at
template_version
📡 PositionGPS
id, registration_id
lat, lng, accuracy_m
recorded_at, received_at
battery_pct, source
partitionné par jour
💬 Cheer
id, from_user_id, to_registration_id
message (text, max 200 chars)
created_at, delivered_at
delivery_status
👀 Subscription
id, spectator_user_id
tracked_registration_id
nickname (ex: "Papa")
created_at
📲 Notification
id, user_id
channel (push/sms/email)
template_key, payload (jsonb)
status, sent_at
locale
📰 NewsPost
id, edition_id
title_fr, title_en
body_fr, body_en
cover_url, published_at
🤝 Sponsor
id, edition_id
name, logo_url, website_url

display_order
🎟️ PromoCode
id, code (unique), edition_id
discount_pct ou discount_xaf
max_uses, current_uses
valid_from, valid_until
👥 Team
id, name, captain_user_id
edition_id, type (corporate/club/family/cause)
logo_url, cause_label
